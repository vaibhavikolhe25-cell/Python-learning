# 💰 Expense Tracker Using Python

A menu-driven Python application designed to record daily expenses, calculate spending, manage monthly budgets, and export expense reports.

## Features

* Add expenses
* View all expenses
* Calculate total spending
* Generate category-wise spending summaries
* View monthly expense summaries
* Search expenses by category, date, or description
* Edit and delete expenses
* Set and monitor monthly budgets
* Store expense data using JSON
* Export expense records to CSV
* Validate user input

## Technologies Used

* Python 3
* JSON
* CSV
* Git and GitHub

## How to Run

1. Install Python 3.
2. Open the Expense-Tracker folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python expense-tracker.py
```

On Windows, you can also use:

```bash
py expense-tracker.py
```

## Learning Outcomes

This project demonstrates Python functions, lists, dictionaries, loops, exception handling, file handling, data aggregation, and CSV export.
